# 🌌 Dimentis OS

A minimal Arch Linux setup focused on aesthetics, performance, and customization.

## ✨ Features

* Hyprland (Wayland)
* Kitty terminal
* Fastfetch with custom ASCII logo
* TokyoNight + Dracula theme mix
* Clean and modern UI
